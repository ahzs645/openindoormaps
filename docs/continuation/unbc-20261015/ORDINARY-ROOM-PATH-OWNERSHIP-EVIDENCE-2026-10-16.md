## A valid future per-path proof

Before dropping any unrelated ordinary-owner prerequisite, independently bind a conservative complete room enclosure to the actual original model, original room identity and full source boundary/threshold operands. Confirm closure without approximate source outlines, display blocks or an unproved bounding box. All unknown/missing boundary operands retain the requirement.

Under an explicitly adopted complete body/turn profile, test the complete stated walking footprint against **every** unrelated ordinary-room enclosure. The existing ordinary-cell centreline predicate and separate per-segment two-foot strips do not provide a standing-footprint or turn-sweep invariant; see the [movement-contract feasibility check](ORDINARY-WALKING-COMPONENT-FEASIBILITY-2026-10-16.md). Any stronger standing-cap or rotation requirement would be an explicit new profile contract, not an existing property. Use exact closed contact: a boundary touch or zero-area contact still retains the owner. A centreline-only or positive-area-only comparison is insufficient. Preserve the original physical floor, holes, foreign material, own doorway qualification and all direction/access policies. Bind any resulting proof to the exact current branch points, endpoints, source-room geometry, model and source-body/schema evidence; changed operands invalidate it.

Required negative controls include a disjoint centreline with a contacting two-foot strip, exact side tangency, a changed room boundary/body, a borrowed neighboring doorway half, an ambiguous original room identity, and copied/stale evidence. Staff, off-limits and non-walkable restrictions stay outside this proposed ordinary-room refinement. Step-free flags remain unknown unless their separate source measurements/reviews establish them.

No swept-footprint owner exclusion was issued in this audit because the necessary original source-enclosure gate is missing for every complete constrained case. Comparing paths with the available drawing or display polygons would not resolve that gate. The next concrete source investigation is 10-1003's two actual wall joins and original doors 2178037/2178100 after fresh-v3 enclosure preparation; the other eight cases also need the named missing owner boundaries in the ledger.
