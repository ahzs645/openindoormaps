## Implemented compiler fix

`indoor-pipeline.ts` originally replayed source edge reviews before `attachNativeCirculationCellRoutes`, which removes and rebuilds native walking branches. Rebuilt branches default to `accessible: unknown` and `enabled: true`; an existing matching confirmation or temporary closure could silently disappear.

The new Reviter helper `lib/reviter/indoor-final-edge-reviews.ts` runs after final native branch construction/reviewed-owner-link replay and before final arrival connectivity checks. It:

- Replays only source reviews for final, existing ordinary native-cell walking branches; it never creates an edge.
- Requires the exact portable key containing model SHA, original endpoint IDs, owner keys and every path coordinate before restoring accessibility metadata.
- Checks that both actual endpoint nodes still match the path, every intermediate coordinate is finite and on the same plane, the cell belongs to the same source model, owners remain walkable/non-staff, and the branch remains a bidirectional walk.
- Refuses reused IDs, endpoint aliases, changed coordinates/owners, direction changes, missing cells and staff/nonwalkable ownership.
- Preserves an explicit source closure conservatively even if old positive geometry evidence is stale.
- Never enables a physically disabled edge and never changes stair/local-step/escalator/door metadata.

This uses the existing portable review contract. It does not broaden the meaning of legacy keys to certify new headroom, thresholds, operating conditions or clearance. Physical geometry must still be rebuilt and validated; reviewers must recheck evidence when those conditions change.

**Current UNBC effect: zero newly approved travelled passages.** There are no saved native-cell reviews in the canonical master to replay. The review fix prevents future checked approaches and closures from being lost after regeneration; the separate 59 stationary identity proofs do not extend the eight reachable step-free pairs. Late native access zones remain applied before cell construction. Strict stair qualification still happens before cell rebuilding; the review helper excludes stairs. Ramp reviews remain handled by the existing source ramp recipe/approach validator. The final replay hook was inspected after integration and has this ordering.
