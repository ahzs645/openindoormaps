# Original-source stepped stair v2 producer

`source-stepped-stair-v2-producer.ts` adds a Node-only source producer. It does not enable a route. It issues a private, process-local source capability only after the actual source adapter reconstructs the complete original source operands and both directions pass the full physical profile.

The fresh constructor accepts original RVT bytes, their expected source checksum, complete original dataset bytes and their expected checksum, original source room bytes bound to that dataset’s `source.roomsSha256`, a particular original edge identity, source run/definition requests, terminal floor recipes, reviewed drawing references, a complete foreign census scope and an untrusted route proposal. It reconstructs the original foreign census, discovers unknown panel/mullion owners from that census, obtains actual source certificates, and constructs original stair, own-body, floor/slab and requested door contexts. Requested retained source IDs are locators; they grant no authority. The implementation contains no fixed UNBC stair, floor, graph edge or station IDs.

`createOriginalSteppedStairV2SourceProofFromSources` can reuse genuine original handles in a retained session. It consumes them through the original private registries again and independently checks the complete original graph bytes. JSON snapshots, copied handles or a self-hashed profile cannot replace them.

`readOriginalSteppedStairV2SourceProof` returns detached exact wire operands, the checked original graph binding and source/implementation receipts. The source index identity hashes its exact physical wire value and native run identity. The private payload also captures the exact original explicit edge review, or its verified absence. A source review with `enabled:false` always refuses; omitted/fabricated source rooms and unresolved packed review values cannot bypass that decision. The private capability is held in a WeakMap; its serialized properties are insufficient to reissue it. Mutating the returned transport cannot mutate the retained source proof.

The payload records direct implementation hashes as a supplement to the enclosing rebuild's full imported-runtime manifest. The final source import must bind that complete closure. The producer captures these direct bindings at module load; later factory/getter calls refuse any changed file. An isolated temporary source-copy test verifies this guard. A complete process-start transitive import freeze is still required: a query-suffix reload cannot prove that already cached dependencies are fresh. A fresh process is required after changing source decoders, source mathematics or constructor policy.

This proof is specific to the requested source run, original terminals and full profile. The production finalizer still checks the newly prepared graph, current valid circulation cells, unchanged room identities/access and every applicable route restriction before enabling the original edge. Stairs remain non-step-free. A successful Library example does not confirm the other held stair links.

Initial validation: five provenance negative tests pass and scoped strict TypeScript checking passes. An independent fresh v13 source session issued the genuine private capability after both complete source directions passed. It used 16 newly issued mullion certificates under the exact constructor flag guard and 52 original panel certificates, bound the original room bytes and verified the absence of an explicit disabled source review. Copied, serialized and plain payloads could not mint a proof; detached transport mutation could not alter it. The complete producer replay took about 62 seconds. Runtime enabling against a fresh rebuilt graph remains a separate pending finalizer check; the saved receipt cannot replace its genuine source capability.

The v13 source profile result predates the later mandatory complete census-scope replay guard. It is retained as historical evidence. A fresh v14 process after the complete issuer/kernel/finalizer freeze is required for the final working graph; cached v13 code or a reloaded producer cannot substitute for that run.
