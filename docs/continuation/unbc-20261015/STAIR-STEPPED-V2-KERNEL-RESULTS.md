## Explicit navigation profile

The prototype uses the project's **two-foot transverse walking width and six-foot swept headroom**, with full two-foot square standing caps at actual flat terminal graph points, flat approach turns and turning-platform bends. It does not require a rigid square at every ordinary tread, and does not certify a complete humanoid shape or human gait. The result reports the exact profile and keeps `humanoidGaitApproved`, `originalSourceAuthorityGranted` and `routeApproved` false.

A rise starts at an actual full-width source-supported station. The following horizontal movement must cross the **exact named finite original riser** across both conservative lateral endpoint tracks, using the body agent's pure exact crossing helper. It never calls the 0.05-foot outward approach point the riser. Actual source typed begin/end flags, original ordered risers, physical tread roles, all physical station heights, full terminal approaches and original graph demands remain mandatory. Material at a named exact foot-support face is distinguished from positive material above that foot plane; all foreign coincident contacts remain vetoes.

Logical/physical height differences are explicit exact operands. No walking segment is added from the nominal graph height through slab material.

Every required original physical occurrence must resolve to nonempty actual cells or an explicit unknown. Missing, duplicated, borrowed, uncensused or declared-empty bodies refuse. **Any unknown refuses immediately**, before expensive exact geometry work. Complete known-cell replay retains closed planar line/point contact, exact head tangency, all own upper flight/slab material and all foreign material. A current original model hash never substitutes for those operands.

The optional door refinement accepts only the new issued placed-trim material certificate; arbitrary owner IDs or supplied cell geometry cannot enter that actual-source path. Plain copied reports have a separate explicitly **untrusted** assembler and cannot become source authority.

Aliases, unsupported consumer branches or missing provenance remain unknown; the GLine/GPoint name by itself is insufficient. The full original primitive ledger stays present.

## Remaining integration boundary

This prototype grants no admission from copied JSON, incoming approval fields or self-hashed geometry. A generic visitor without the original RVT cannot independently prove original model membership from a small hash manifest. Source package import must reconstruct the source index from actual original model/graph contexts and compare it exactly; the visitor then replays the preserved complete mathematical operands under the existing prepared-source trust boundary. A stronger arbitrary-untrusted-visitor source guarantee needs original source bytes or independently authenticated source authority.

Before wiring the new discriminant into production, independently review this kernel, finish the foreign source body census, run the actual-source entry point and full access/physical compiler checks, preserve all version 1 behavior, update source/visitor/worker validators and projection together, and calculate real routes up and down. All original held stairs remain disabled meanwhile.
