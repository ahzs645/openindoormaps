## Why no automatic conversion was made

The current Building 07 level-311 circulation candidates do not form a unique seventeen-identity set. Room labels, `circulation:true`, alphabetic sorting, the complement of the staff polygon and current connectivity cannot reconstruct the exact image the user approved. Some native regions contain several room identities; geometry grouping is also not a permission grant. The source-index file retains the stable identities and geometry hashes so a recovered legend can be bound precisely without a fresh authorization request.

The recoverable next input is the original Q3.4 question image/HTML/rendering JSON or the later original RUN/session export that created it. A readable screenshot must show the letters and identifiable native geometry/room references; then verify the correspondence against original model/room hashes and preserve boundaries. Any proposed mapping remains unapplied until this correspondence is established. The existing four explicitly public records and eight staff records remain unchanged throughout.
