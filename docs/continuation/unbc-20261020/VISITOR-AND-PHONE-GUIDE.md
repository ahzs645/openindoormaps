# UNBC visitor concept and later phone check

Updated October 20, 2026 · America/Vancouver. Draft for the forthcoming software candidate; its test link and exact test journeys are pending. The existing private Site is historical version 14. No new route, phone or venue result is approved by this guide.

## The simple journey

Find a place → confirm building/floor → choose a known starting place → select Walking or Step-free → preview and follow the instructions. Use Previous/Next for each turn and floor change. Starting position and arrival are manual; indoor GPS and automatic arrival are not assumed.

Keep complete-map download secondary to directions. Show “saved for offline use” only after the app, map, routing data, floor plans and fonts are completely saved and verified. The costly building-model preparation belongs before delivery; visitors should receive checked prepared assets.

Start with a finite list of useful entrance-to-destination journeys. Verify each advertised journey in both directions and offered profiles. A held stair can stay unavailable while a qualified alternative serves the journey. Step-free must exclude stairs and provide an accepted alternative or a clear refusal. Unknown access or a same-floor stair approach is not permission to use the flight.

## Test after software acceptance

The user will test afterward. Use the final candidate link and journey list on iPhone Safari and Android Chrome. Leave an unavailable device or unfinished check marked untested. Record model, OS/browser version, candidate version, date, network and a short screen recording.

1. Start fresh online. Time page opening until the correct floor is usable, directions request until complete instructions, and total opening-to-route time. Select the known start and destination manually; confirm names/floors.
2. Check Walking, reverse the journey, then Step-free in both directions. Check Previous/Next, floor changes, warnings and clear held-stair refusal. Old-profile instructions must disappear after a profile change.
3. On site, follow only supplied checked journeys. Compare signs, door operation, thresholds/clear widths with units, obstacles, hours/restrictions, lift operation/served floors and the final standing point. Photograph discrepancies; keep unknowns marked unknown.
4. Save the complete app/map. Interrupt once and check resume. After complete-save confirmation, turn off Wi-Fi and cellular, close/reopen, check all supplied floors/fonts/instructions and request a fresh route. Record offline floor/route times separately.

Send one record per journey: **start→destination; profile; online/offline; timings; passed/failed/untested; what happened; photo/recording**. Software success does not establish physical access or the correct arrival side.
