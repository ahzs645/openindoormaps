## Notes

- "Engine" features (routing, accessibility, floor filtering, one-way
  escalators) live in `app/indoor-directions/` and are identical across modes —
  modes differ only in chrome, which is the point of the comparison bench.
- Store "brand" data is now carried through the vendor ports and rendered in
  the location card: Pointr `openHours`/`rating`/`price`/`keywords`/`buttons`
  and Mappedin `operationHours`/`phone`/`social`/`tags`/`states` (see the
  metadata table in `docs/viewer-data-models.md`). Hours are evaluated in the
  viewer's local clock, not the venue timezone.
- The mappedin-05 screenshot shows a corrected floor-change label: downward
  stair traversal now says "to Level 1" (was "to Level 2" before the
  traversal-direction fix).
